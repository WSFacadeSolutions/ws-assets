# Marketing Plan v3 — scheduler-ready media

This directory holds versioned final media produced after the approval-board stage
was retired on 12 August 2026. The WST010 scheduler is the review surface; this
directory preserves the production masters and source provenance.

## Public treatment

- Photography leads. No recurring logo panel, campaign title or blurred overlay.
- Every feed image is exported at 1080 × 1350 pixels, JPEG quality 92.
- A carousel exists only when the sequence adds a genuinely different reading.
- Reusing a project is acceptable; reusing the same photograph is not.
- Captions and published text use Australian English.

## Duplicate audit

Every selected photograph was visually compared with the published WSD001 slides,
all pending WSD001 slides and relevant WSD003 video frames. The audit rejected the
St Ives front elevation, the Cecil Hills moulding detail, the Paddington close arch,
the Baulkham Hills entry and a Dover Heights balcony angle because they repeated or
too closely echoed existing media.
