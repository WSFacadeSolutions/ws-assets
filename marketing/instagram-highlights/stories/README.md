# Instagram Highlight Story sets

Upload-ready 1080 × 1920 static Stories for the `Work`, `Services` and `Team`
Highlights. Public-facing copy uses Australian English.

## Editorial system

- `Work` — five edge-to-edge project photographs with a restrained project,
  location and scope label. There are no logos, cards or campaign-template
  devices over the work.
- `Services` — eight reference pages, one for each WS solution. Each page uses
  the exact service and subservice wording from the WS capability statement and
  website.
- `Team` — three real-photo pages: site leadership, field craft and the shared
  standard. AI-generated portraits were audited and deliberately excluded from
  this permanent trust surface.

All text and essential visual content sits inside the Instagram Story safe area.
The sets are silent by design: they are reference content browsed at the viewer's
pace, while the `WS` Highlight remains the continuous audiovisual sequence.

## Recommended publication order

- `Work`: 23 August 2026, 5:30 pm Sydney
- `Services`: 30 August 2026, 5:30 pm Sydney
- `Team`: 6 September 2026, 5:30 pm Sydney

After each set has published, add the archived Stories to its matching Highlight
in filename order and select the prepared cover from `../../covers/png/`.

## Structure

- `*/source/` contains the real source photograph used for each Story.
- `*/final/` contains the scheduler-ready JPEG.
- `build_stories.sh` regenerates the complete set from the committed sources.

The `Labour Hire` Story uses the provisional real WS on-site leadership photo
approved for the capability statement. Replace it only when a stronger dedicated
field photograph is available.
