# Instagram Highlights covers

Upload-ready cover system for the first four WS Instagram Highlights.

## Initial order

1. `WS` — company standard, capability, compliance and credentials
2. `Work` — completed-project evidence
3. `Services` — concise service map
4. `Team` — leadership and field team

`Process` is deliberately deferred until the field-media intake can maintain it
with consistently strong material.

## Files

- `covers/svg/` contains the editable vector masters.
- `covers/png/` contains 1080 × 1920 upload files.

The visible artwork is centred inside the safe circular crop around the Story
canvas centre. This allows the same file to be uploaded as a Story and selected
as its Highlight cover without losing the symbol to Instagram's circular mask.
The titles do not appear inside the artwork because Instagram labels each
Highlight beneath the cover.

## Treatment and sources

- White ground: `#FFFFFF`
- Petroleum ink: `#1E2F38`

The `WS` cover uses the official square mark without alteration. `Work` and
`Services` use the existing icon artwork published on `wssolutions.au`; no new
symbol language was invented for them. `Team` uses a simple three-person outline
matched to the same two-unit line weight as the site icons. All four covers
deliberately use one icon, one colour and no decorative frame.
