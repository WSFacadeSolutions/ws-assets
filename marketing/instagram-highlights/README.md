# Instagram Highlights covers

Upload-ready cover system for the first four WS Instagram Highlights.

## Initial order

1. `WS` — company standard, capability, compliance and credentials
2. `Work` — completed-project evidence
3. `Services` — concise service map
4. `Team` — leadership and field team

`Process` is deliberately deferred until the field-media intake can maintain it
with consistently strong material.

## Files

- `covers/svg/` contains the editable vector masters.
- `covers/png/` contains 1080 × 1920 upload files.

The visible artwork is centred inside a 700 × 700 pixel safe circle around the
Story canvas centre. This allows the same file to be uploaded as a Story and
selected as its Highlight cover without losing the symbol to the circular crop.
The titles do not appear inside the artwork because Instagram labels each
Highlight beneath the cover.

## Treatment

- WS off-white ground: `#F5F2F0`
- Petroleum ink: `#1E2F38`
- Lilac accent: `#A490FF`
- Neutral hairline: `#D9D3CF`

The `WS` cover uses the official square mark without alteration. The other three
symbols are purpose-built for this set and are not intended to replace brand or
service logos.
